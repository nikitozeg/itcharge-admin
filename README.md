# Аналитика зарядок IT Charge

Статическая админка с графиками использования зарядных станций из [IT Charge](https://cp.itcharge.ru).

- Вход — те же email и пароль, что на cp.itcharge.ru. Запросы идут из браузера напрямую в `api.itcharge.ru`.
- Токен сессии хранится в localStorage, транзакции — в IndexedDB этого браузера. В репозитории и на хостинге данных нет.
- «Выйти» удаляет и токен, и кэш.

Локально: `python3 -m http.server 8093` в этой папке → http://localhost:8093

## Уведомления в Telegram

`.github/workflows/notify.yml` раз в 5 минут (GitHub бывает запаздывает до 10–15 минут) запускает `notifier/notify.mjs`: скрипт берёт последние 50 транзакций и публикует в канал итог каждой новой завершённой зарядки. Отменённые без энергии пропускаются. При первом запуске ничего старого не публикуется.

Там же проверяется связь станций: если станции нет на связи дольше 5 минут, в канал уходит «🔴 нет связи», а когда связь вернётся — «🟢 снова на связи» с длительностью простоя. Демонтированные станции (archived в IT Charge) пропускаются.

Уже опубликованные зарядки и отправленные тревоги хранятся в ветке `notifier-state`.

Секреты репозитория (Settings → Secrets and variables → Actions): `ITCHARGE_EMAIL`, `ITCHARGE_PASSWORD`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (`@имя_канала` или числовой id вида `-100…`). Бот должен быть админом канала с правом публикации.

Проверка: Actions → «Уведомления о зарядках» → Run workflow → галочка «Отправить в канал последнюю зарядку».
