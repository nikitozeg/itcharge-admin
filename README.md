# Аналитика зарядок IT Charge

Статическая админка с графиками использования зарядных станций из [IT Charge](https://cp.itcharge.ru).

- Вход — те же email и пароль, что на cp.itcharge.ru. Запросы идут из браузера напрямую в `api.itcharge.ru`.
- Токен сессии хранится в localStorage, транзакции — в IndexedDB этого браузера. В репозитории и на хостинге данных нет.
- «Выйти» удаляет и токен, и кэш.

Локально: `python3 -m http.server 8093` в этой папке → http://localhost:8093

## Уведомления в Telegram

Cloudflare Worker `worker/` (логика — `notifier/core.mjs`) раз в минуту проверяет IT Charge и пишет в канал:

- итог каждой новой завершённой зарядки (отменённые без энергии пропускаются; при первом запуске старое не публикуется);
- «🔴 нет связи», если станции нет на связи дольше 5 минут, и «🟢 снова на связи» с длительностью простоя; демонтированные станции (archived) пропускаются;
- «❌ не удаётся зарядиться», если попытка отменилась без энергии и клиент за 5 минут так и не начал заряжаться: разъём, попытки, причина остановки по данным станции, сколько раз клиент заряжался у нас раньше, номера транзакций; если потом зарядится — ответ «✅ всё же зарядился»;
- «📞 позвоните клиенту» сразу, если у того же клиента вторая неудачная попытка в течение 20 минут (без удачной зарядки между ними): с телефоном клиента, ответом на тревогу, если она уже была. Телефон запрашивается в момент отправки и нигде не хранится; в публичном канале он не показывается;
- после 22:00 МСК — итог за сутки с 22:00 прошлого дня: сумма в рублях, число зарядок и кВт⋅ч по станциям; зарядка относится к суткам, в которые закончилась.

Состояние (опубликованные зарядки, тревоги, дата последнего итога) и токен IT Charge хранятся в D1 `itcharge-notifier`, таблица `kv`.

Секреты воркера: `ITCHARGE_EMAIL`, `ITCHARGE_PASSWORD`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (`@имя_канала` или `-100…`), `ADMIN_KEY`. Бот должен быть админом канала с правом публикации.

```bash
cd worker
npx -y wrangler@4 deploy                     # выкатить изменения
npx -y wrangler@4 secret put TELEGRAM_CHAT_ID # задать или сменить секрет
npx -y wrangler@4 tail                       # смотреть логи проверок
```

Статус: https://itcharge-notifier.nikitoz777.workers.dev. Ручной запуск: `POST /run` с заголовком `authorization: Bearer <ADMIN_KEY>`, а `?test=1` отправит в канал последнюю зарядку и статус станций.
